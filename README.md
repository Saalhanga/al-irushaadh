# AL IRUSHAADH

**الإرشاد**

Kudahuvadhoo Shiekhs Digital Islamic Knowledge & Media Archive

## About

AL IRUSHAADH is a professional, modern, multilingual Islamic digital media and knowledge archive dedicated to the scholars and speakers of Kudahuvadhoo.

The platform serves as:

- A digital archive of Kudahuvadhoo Shiekhs
- An Islamic media library
- A searchable knowledge platform
- A discovery platform for relevant external content
- A long-term digital preservation system

## Tech Stack

- Frontend: Vite + TypeScript + React + shadcn/ui + Tailwind CSS
- Backend & Storage: Supabase/PostgreSQL
- Auth: Admin login using email/password

## Features

- Multilingual interface (Dhivehi, English, Arabic)
- Sheikh directory and profiles
- Topic-based content discovery
- Collections and playlists
- Advanced search with suggestions
- Persistent global audio player
- Public content submission with admin moderation
- Admin dashboard with analytics
- RTL support for Dhivehi and Arabic
- Mobile-first responsive design
